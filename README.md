# 🎮 Tic-Tac-Toe Game (Player vs Computer)

A simple Tic-Tac-Toe game built with Python and Tkinter where the player plays as **X** and the computer plays as **O**.

## ✨ Features

- 🧑 Player vs Computer mode
- 🤖 Computer automatically makes moves
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 New Game button
- 🎨 Simple GUI using Tkinter

## 🎯 Game Rules

1. Player always starts as **X**.
2. Computer plays as **O**.
3. First player to make a row, column, or diagonal wins.
4. If all boxes are filled and no winner is found, the match is a draw.
